# Cloudreach

An original browser-based cloud universe. It uses layered, low-poly billows, an atmospheric fog gradient, a shared sun/sky light setup, and slow formation drift. No VDB asset is used or required.

The formation brief was informed by the broad, dense cloud arrangements described by [VDB Clouds Pack 17: Formations 2](https://www.thepixellab.net/vdb-clouds-pack-17-formations). Its implementation choices also take inspiration from the published atmospheric approach in [Sam1983Aing/kelingking](https://github.com/Sam1983Aing/kelingking): flat bases, rounded tops, coherent sun lighting, haze, and a clear navigable sky. The Cloudreach source code and geometry are original.
